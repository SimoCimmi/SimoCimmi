### Progetti in Evidenza

#### Ricerca, VR & Intelligenza Artificiale
*   **[Definizione di Pazienti Virtuali con LLM](https://github.com/SimoCimmi/Training_VR_VP_ChestPain)** - *Progetto di Tesi (Sesa Lab)* \
    Sviluppo di pazienti virtuali per la diagnosi di attacchi di panico e infarti al miocardio causati da dolore toracico utilizzando la realtà virtuale. A seguito di una valutazione tra 4 LLM, il sistema integra Gemma-2 per l'anamnesi medica in un ambiente virtuale realizzato con Unity3D, sfruttando il concetto di Gamification come tecnica di teaching.
*   **[Dog-Skin-Diseases-Classifier](https://github.com/SimoCimmi/Dog-Skin-Diseases-Classifier)** - *Team Developer* \
    Sviluppo di un sistema di classificazione automatica per 6 patologie cutanee canine per supportare la diagnosi veterinaria. Sviluppo delle pipeline di addestramento (DVC, PyTorch) per reti neurali convoluzionali (ConvNeXt, EfficientNetV2).

#### Architetture Backend & Software Engineering
*   **[Piattaforma SafePet - Backend](https://github.com/Progetto-SafePet/SafePet_backend)** *Team Developer*
*   **[Piattaforma SafePet - Frontend](https://github.com/Progetto-SafePet/SafePet_frontend)** *Team Developer* \
    Piattaforma web per la digitalizzazione e centralizzazione dei dati sanitari degli animali da compagnia. Oltre allo sviluppo backend (Java, Spring Boot, MySQL) e frontend (React, Vite), sono state condotte pratiche di test (Category Partition) e di CI/CD.
